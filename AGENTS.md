- The static website lives in `outputs/snabservis-site/dist/`: `index.html`, `app.js`, `styles.css`, and `assets/`.
- Project documentation is `outputs/snabservis-site/README.md`.
- Keep the existing delivery archives in `outputs/special-steels-northwest-site.zip` and `outputs/snabservis-site.zip` current when changing the website.
