# Специальные стали Северо-Запада

Сайт-каталог металлопроката. Этот репозиторий — основная рабочая копия проекта.

## Продолжить работу на другом компьютере

1. Склонируйте этот репозиторий через Git или GitHub Desktop.
2. Откройте папку репозитория как локальный проект в Codex.
3. Отправьте сообщение:

   > Продолжи сайт «Специальные стали Северо-Запада». Прочитай AGENTS.md и outputs/snabservis-site/README.md, запусти предпросмотр. Сохраняй изменения в этом репозитории.

Инструкции для Codex находятся в `AGENTS.md`. Для продолжения работы достаточно файлов проекта; старая папка на первом компьютере не нужна.

## Открыть сайт

Без установки зависимостей откройте `outputs/snabservis-site/dist/index.html` в браузере.

Для предпросмотра по локальному адресу, если установлен Python 3, выполните из корня репозитория:

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory outputs/snabservis-site/dist
```

На macOS/Linux команда Python может называться `python3`.

Адрес: <http://127.0.0.1:4173/#catalog-krug>. Сервер запускается отдельно на каждом компьютере.

## Структура

- `outputs/snabservis-site/dist/` — HTML, CSS, JavaScript, логотипы и шрифты сайта.
- `outputs/snabservis-site/README.md` — описание возможностей и ограничений.
- `outputs/special-steels-northwest-site.zip` и `outputs/snabservis-site.zip` — готовые архивы сайта.
- `outputs/*.svg` — отдельные версии логотипа и знака с тиглем.

## Текущее состояние

- Разделы «Поковка стальная», «Круг», «Квадрат» и «Шестигранник».
- В разделе «Круг» 19 позиций, включая 16 диаметров ХН35ВТ от 50 до 150 мм.
- Справа в каталоге кругов — фильтр по маркам стали; на телефоне он открывается кнопкой «Фильтры».
- Добавление и удаление товаров из корзины прямо из каталога.
- Локальная корзина, прайс-лист CSV и заявки TXT.
- Цена и наличие добавленных кругов, квадрата и шестигранника требуют уточнения.

Сайт статический: корзина хранится в браузере, формы скачивают заявку и не отправляют её менеджеру автоматически. Контактные данные пока оставлены из исходного образца. Публичное размещение сайта — отдельная задача.

## Обмен изменениями

Перед работой на другом компьютере получите изменения через Pull. После правок сохраните их коммитом и отправьте через Push. В GitHub Desktop это действия Fetch/Pull, Commit и Push origin. Не редактируйте одновременно одни и те же файлы в двух копиях без синхронизации.

Промежуточные материалы `work/` и неиспользуемое изображение исходного бренда исключены из Git; для работы сайта они не нужны.
